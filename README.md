## ✨ Fitur Utama:
1. **Offline-First & Multi-HP**: Ekspor/impor file JSON per-lantai via Bluetooth/Share/Telegram tanpa server terpusat.
2. **Kamera Barcode Scanner**: Pindai cepat dengan suara beep audio interaktif.
3. **Modal Penyesuaian Stok**: Stok diubah via modal popup (+1, +5, -1, -5, custom delta) dengan pencatatan nama staf otomatis.
4. **Ubah Password Mandiri**: Setiap petugas dapat mengubah password akun masing-masing langsung di aplikasi.
5. **Navigasi Terisolasi**: Penjaga lantai hanya melihat lantai kerja yang menjadi tanggung jawabnya.
6. **Auto-Backup Telegram Bot**: Otomatisasi pencadangan database ke Telegram Channel/Chat saat terhubung internet.
7. **Laporan Teks Bersih**: Pembuatan laporan rekapitulasi WhatsApp/Telegram yang rapi dan profesional.
